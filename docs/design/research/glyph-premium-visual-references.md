# Glyph premium visual references

Target quality: sit credibly beside Apple/macOS, Raycast, Linear, Behance, Figma, GitHub. Synthesize, never clone. Color intent (from direction): off-white/white canvas, excellent near-black type, cool-neutral secondary surfaces, one restrained warm accent (not the identity), large game media, polished shell, subtle material depth. ✅ = live-inspected this pass.

## Behance — For You / discovery ✅ (live)
- **Screen:** work discovery grid.
- **Patterns:** one integrated toolbar (Filter chip + a single generous rounded search with a "Projects ▾" scope selector + view toggle) — *no second horizontal nav bar*; horizontally-scrollable category pills with a chevron affordance; a section label with a right-aligned inline action; a grid of **large cinematic media tiles** where the cover art dominates and title/creator are small and secondary.
- **Why polished:** the work is the content; chrome recedes; one search surface, not three bars; consistent big aspect-ratio media.
- **Glyph learns:** kill the stacked "Explore label + search + second nav" chrome → one integrated toolbar; make project media large and cinematic; titles/creator subordinate to the game image; category chips for browse.
- **Don't copy:** engagement metrics (appreciations/views), infinite algorithmic "For You," ad tiles.

## Linear — app shell / lists ◑
- **Patterns:** a quiet, grouped left sidebar (workspace → sections → items) with a *subtle* selected state (soft filled row, no loud color block); dense lists with generous row height and hairline separators; near-zero decorative color — accent only on the active/primary action; command-K everywhere; fast, restrained 120–180ms transitions.
- **Why polished:** hierarchy from weight + spacing + one selection treatment, not from boxes or color; ruthless chrome reduction.
- **Glyph learns:** sidebar grouping + one refined selection treatment; density without chaos; a command surface; motion restraint.
- **Don't copy:** issue-tracker density everywhere (discovery must breathe); Linear's cool-gray-on-gray flatness for a media product.

## Raycast — command + compact panels ◑
- **Patterns:** compact but beautiful rows with crisp icon optical alignment; a strong right-hand detail/context panel beside a list (two-pane); immaculate hover/pressed/selected states; keyboard-hint chips (⌘K, ↵); layered panels with subtle elevation and a fine inner border.
- **Why polished:** every row/menu/field has a deliberate state; nothing feels like default browser UI; two-pane uses width.
- **Glyph learns:** a contextual right rail beside content (uses the 1440 canvas); keyboard affordances; per-state interaction polish; layered panel depth via border+shadow, not glass.
- **Don't copy:** launcher-only density as the whole product; monochrome.

## Apple / macOS (Finder, System Settings, App Store) ◑
- **Patterns:** generous but disciplined spacing; a translucent grouped sidebar; large clear titles with tight tracking; content-first pages; App Store's big editorial feature card + horizontal media shelves; impeccable optical alignment and touch-target precision; selective vibrancy only on chrome.
- **Why polished:** reduction, hierarchy, consistency, quality type — not "more glass."
- **Glyph learns:** App Store's **feature card + media shelves** model for Explore; large tracked titles; content-first restraint; translucency reserved for sticky chrome only.
- **Don't copy:** fake macOS window chrome inside a web app; blur everywhere.

## GitHub / Primer ◑
- **Patterns:** persistent object identity (repo header stays while subviews switch — Code/Issues/PRs); predictable object→subview IA; dense metadata that stays legible (language dot, topics, "Updated N ago"); mature empty/loading/error states.
- **Why polished:** you always know what object you're in and how its parts relate; density without chaos.
- **Glyph learns:** persistent **Project identity header** across Devlog/Playtest/Collaboration subviews (reduces reorientation — GitHub keeps repo identity while switching tabs; Glyph applies it to the Project); predictable Developer→Project→Devlog IA.
- **Don't copy:** gray density as a media product's default; star/fork social proof.

## Figma / Framer / Vercel ◑
- **Figma:** file/community grid with large thumbnails + a compact toolbar; refined dark canvas chrome around light content.
- **Framer/Vercel:** editorial marketing polish — big tracked display type, layered subtle depth, restrained accent — useful for Landing, not app UI.
- **Glyph learns:** big-thumbnail community grid (Explore), compact toolbar; reserve marketing expressiveness for Landing.
- **Don't copy:** canvas-tool chrome for a content product.

## Synthesis → the three directions to prototype
- **A "Studio" — Apple/macOS clarity + dev-tool precision:** off-white canvas, refined grouped sidebar, App-Store-style feature card + media shelves, calm generous spacing, thin material hierarchy, one warm accent, subtle elevation.
- **B "Showcase" — Behance editorial + developer structure:** large cinematic media, ambitious asymmetric grid, expressive overlaid project titles, work-first discovery, editorial section rhythm.
- **C "Console" — Raycast/Linear polish + game identity:** three-column (nav + content + contextual rail), denser compact identity, command search, keyboard affordances, layered panel depth — uses the full canvas.

Each prototype: off-white/near-black/cool-neutral base + restrained warm accent + large media; judged against "credible beside Apple/Raycast/Linear/Behance/Figma/GitHub?"
