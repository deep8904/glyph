# Visual References

`moodboard.svg` is a transformed analytical moodboard. It summarizes palettes, composition, and useful ideas from the eight preferred Dribbble references without copying or redistributing the original artwork.

Use it for alignment, then inspect the originals via the links in [../MOODBOARD_REFERENCE_CATALOG.md](../MOODBOARD_REFERENCE_CATALOG.md).

Why no downloaded screenshots: the source artwork belongs to its creators and reuse permissions vary. Direct links preserve attribution and let the implementation team inspect the current source at full quality.
